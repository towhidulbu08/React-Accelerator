6.useTransition Hook:
The useTransition hook is a React hook that provides a way to handle UI transitions and background state updates, such as deferred states. It helps improve the user experience by allowing React components to render smoothly without blocking the UI during longer-running updates. Here's a breakdown of its purpose, usage, and an example.

=>Purpose of useTransition:
i.When a state update takes a long time to complete, React might freeze the UI, making it feel sluggish. This often happens with large lists, complex calculations, or server requests.

ii.useTransition enables these updates to be marked as non-urgent, allowing React to continue rendering the more urgent updates immediately (e.g., user input) while the background update occurs in parallel.

const [isPending, startTransition] = useTransition();
isPending: A boolean indicating whether the non-urgent update is still in progress.
startTransition: A function used to wrap the non-urgent updates. When you call it, the updates inside are treated as low-priority.

7.useDeferredValue hook:
The useDeferredValue hook in React is used to defer the update of a value until the browser is less busy. It's useful when you want to prevent blocking the main thread, especially for performance optimization in scenarios like large re-renders, expensive computations, or when waiting for user inputs that don't need to be handled immediately.

Here’s how it works:

Basic Usage:

import { useState, useDeferredValue } from 'react';

function SearchComponent({ search }) {
  const [query, setQuery] = useState('');
  
  // The deferred value is the one that will update more slowly
  const deferredQuery = useDeferredValue(query);

  const handleInputChange = (e) => {
    setQuery(e.target.value);
  };

  // Use deferredQuery in places where a delayed update is fine
  const filteredSearchResults = search(deferredQuery);

  return (
    <div>
      <input type="text" value={query} onChange={handleInputChange} />
      <ul>
        {filteredSearchResults.map((result, index) => (
          <li key={index}>{result}</li>
        ))}
      </ul>
    </div>
  );
}
Explanation:
i.query: This is the actual input value the user is typing.
ii.deferredQuery: This is a deferred version of query, which updates at a slower pace.

Instead of immediately updating UI based on query, useDeferredValue will delay the update until the browser is free, helping avoid performance bottlenecks when dealing with expensive operations or UI rendering.
When to use useDeferredValue:
It's handy in search input fields where user typing doesn't need instant filtering but should be deferred to reduce the re-render burden.
In long lists or heavy components where re-rendering frequently on every small change might be expensive.

=>Note:The Array.from() method in JavaScript creates a new array from an array-like or iterable object. It also allows for optional mapping (transformation) of the values, similar to how .map() works. This method is useful when you want to convert other data structures or objects into arrays. Set, Map , string, array are the examples of iterable objects


Array.from(arrayLike, mapFunction, thisArg);
arrayLike: The array-like or iterable object to convert to an array.
mapFunction (Optional): A function that is called for every element of the array, just like .map().
thisArg (Optional): A value to use as this when executing the mapFunction.
Example 1: Converting a String to an Array
Array.from can convert a string into an array of its individual characters.

javascript
Copy code
const str = "Hello";
const array = Array.from(str);
console.log(array); // Output: ['H', 'e', 'l', 'l', 'o']
Example 2: Converting a Set to an Array
If you have a Set of unique values, you can convert it to an array using Array.from().

javascript
Copy code
const mySet = new Set(['a', 'b', 'c']);
const array = Array.from(mySet);
console.log(array); // Output: ['a', 'b', 'c']
Example 3: Using Array.from with a Mapping Function
Array.from can take a mapping function as its second argument, which allows you to transform each element as it is created.

javascript
Copy code
const squares = Array.from([1, 2, 3, 4], x => x * x);
console.log(squares); // Output: [1, 4, 9, 16]
Example 4: Creating an Array of a Given Length
Array.from can generate an array of a specific length and fill it with values using a mapping function.

javascript
Copy code
const length = 5;
const incrementArray = Array.from({ length: length }, (_, index) => index + 1);
console.log(incrementArray); // Output: [1, 2, 3, 4, 5]
In this example:

{ length: length } creates an array-like object with a length property.
The mapping function (_, index) => index + 1 uses the index to populate the array elements.
Example 5: Converting Arguments Object to an Array
Array.from is useful when you want to convert array-like objects, such as the arguments object, into a true array.

javascript
Copy code
function sum() {
  const argsArray = Array.from(arguments);
  return argsArray.reduce((acc, val) => acc + val, 0);
}

console.log(sum(1, 2, 3, 4)); // Output: 10
Here, arguments is an array-like object, but it does not have array methods. Using Array.from converts it into a real array, allowing you to use methods like .reduce().

=>Key Takeaway:
Array.from is versatile and can handle array-like objects (like strings or arguments), iterable objects (like sets and maps), and even plain objects with a length property.
It can be used with or without a mapping function, making it a powerful tool for generating and transforming arrays.
