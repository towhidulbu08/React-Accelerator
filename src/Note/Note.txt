        <==>L-5.6: React Lazy Load <==>

Note: Package Install-> React Feather

=>In React, lazy loading is a technique that allows you to load components only when they are needed, rather than loading everything upfront. This improves the performance of the application, especially when dealing with large components or applications with many routes.

React provides a built-in function called React.lazy() to implement lazy loading of components. When a component is lazy-loaded, it is only fetched and rendered when it is required, reducing the initial load time of the app.

=>How it Works:
Before lazy loading: All components are loaded when the application starts, which can slow down the initial load time.
With lazy loading: Components are loaded dynamically only when they are rendered, improving the performance by splitting the app into chunks.
Usage Example:
jsx
Copy code
import React, { Suspense } from 'react';

// Use React.lazy to lazy load the component
const LazyComponent = React.lazy(() => import('./LazyComponent'));

function App() {
  return (
    <div>
      {/* Suspense component is used to wrap the lazy-loaded component */}
      <Suspense fallback={<div>Loading...</div>}>
        <LazyComponent />
      </Suspense>
    </div>
  );
}

export default App;
Explanation:
React.lazy(): This is used to import the component you want to lazy load. The argument passed is a function that returns a dynamic import().

Suspense: Since lazy-loaded components are asynchronous, React provides the Suspense component to display a fallback (like a loading spinner or message) while the lazy-loaded component is being fetched. The fallback prop defines what should be shown while the component is loading.

Use Cases for Lazy Loading:
Large components that are not immediately visible when the page loads.
Components in routes that are conditionally rendered.
Parts of the app that are only needed when the user interacts with certain sections (e.g., modals, popups).
By using lazy loading, you can optimize your app's performance, particularly for larger apps with lots of routes and components.
