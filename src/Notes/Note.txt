<==>L-4.2 Manipulating the DOM with Refs - Getting a ref to the node<==>

React automatically updates the DOM to match your render output, so your components won’t often need to manipulate it. However, sometimes you might need access to the DOM elements managed by React—for example, to focus a node, scroll to it, or measure its size and position. There is no built-in way to do those things in React, so you will need a ref to the DOM node.

You will learn:
i.How to access a DOM node managed by React with the ref attribute
ii.How the ref JSX attribute relates to the useRef Hook
iii.How to access another component’s DOM node
iv.In which cases it’s safe to modify the DOM managed by React


=>Getting a ref to the node: 
To access a DOM node managed by React, first, import the useRef Hook:

import { useRef } from 'react';
Then, use it to declare a ref inside your component:

const myRef = useRef(null);
Finally, pass your ref as the ref attribute to the JSX tag for which you want to get the DOM node:

<div ref={myRef}>

=>While DOM manipulation is the most common use case for refs, the useRef Hook can be used for storing other things outside React, like timer IDs. Similarly to state, refs remain between renders. Refs are like state variables that don’t trigger re-renders when you set them. Read about refs in Referencing Values with Refs.

=>Deep Dive:
How to manage a list of refs using a ref callback:The solution is to pass a function to the ref attribute. This is called a ref callback. React will call your ref callback with the DOM node when it’s time to set the ref, and with null when it’s time to clear it. This lets you maintain your own array or a Map, and access any ref by its index or some kind of ID.
