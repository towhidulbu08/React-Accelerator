<==> 4.28 Performance Optimization <==>

=>>  Memoization is an optimization technique where the results of expensive function calls are cached, so that the same results can be returned quickly if the function is called again with the same inputs.

In React, this concept is commonly used with components or functions to avoid unnecessary re-renders and calculations.

Example of "memorize" in React:

1.Using React.memo:

React.memo is a higher-order component that memoizes the rendered output of a functional component. If the component’s props don’t change, React will skip rendering the component again.

Example:
const MyComponent = React.memo(function MyComponent(props) {
  // Render logic here
});
Bangla Explanation:

React.memo এর মাধ্যমে কোনো কম্পোনেন্টের আউটপুট মুখস্থ করা হয়। যদি কম্পোনেন্টের প্রপসগুলো না বদলায়, তাহলে React পুনরায় কম্পোনেন্টটি রেন্ডার করা এড়িয়ে যায়।

2.Using useMemo:

useMemo is a React Hook that memoizes the result of a computation. It only re-computes the memoized value when one of the dependencies has changed.

Example:


const memoizedValue = useMemo(() => computeExpensiveValue(a, b), [a, b]);
Bangla Explanation:

useMemo ব্যবহার করে, React একটি ব্যয়বহুল গণনার ফলাফল মুখস্থ করে রাখে এবং নির্দিষ্ট ডিপেন্ডেন্সি পরিবর্তিত হলে তবেই তা পুনরায় গণনা করে।

By memoizing in React, developers can optimize the performance of their applications by preventing unnecessary re-renders and calculations, especially in complex components or with expensive operations.

3.Using useCallBack:

In React, useCallback is a Hook that returns a memoized version of a callback function. It is useful when you want to ensure that a function maintains the same reference across renders, unless its dependencies change. This can help optimize the performance of your application, especially when passing callback functions to child components that might cause unnecessary re-renders.

When to Use useCallback:
When you have a function that is passed down to child components as a prop and you want to prevent those components from re-rendering unnecessarily.
When you have a function that is used as a dependency in another Hook (e.g., useEffect or useMemo) and you want to ensure that it doesn't change unless its dependencies do.

const memoizedCallback = useCallback(() => {
  // Your logic here
}, [dependency1, dependency2]);

Example:
j
import React, { useState, useCallback } from 'react';

function ParentComponent() {
  const [count, setCount] = useState(0);

  const increment = useCallback(() => {
    setCount((prevCount) => prevCount + 1);
  }, []);

  return (
    <div>
      <ChildComponent increment={increment} />
      <p>Count: {count}</p>
      <button onClick={increment}>Increment</button>
    </div>
  );
}

function ChildComponent({ increment }) {
  console.log('ChildComponent rendered');
  return (
    <button onClick={increment}>Child Increment</button>
  );
}
Explanation:
Without useCallback: The increment function would be recreated on every render of ParentComponent, causing ChildComponent to re-render each time, even if it didn’t need to.

With useCallback: The increment function is memoized, meaning it will only be recreated if the dependencies change. Since the dependencies array is empty ([]), the increment function will maintain the same reference across renders, preventing unnecessary re-renders of ChildComponent.

Bangla Explanation:
useCallback হল একটি React Hook যা একটি কলব্যাক ফাংশনের মুখস্থ সংস্করণ ফেরত দেয়। এটি তখনই পুনরায় তৈরি হয় যখন নির্দিষ্ট ডিপেন্ডেন্সিগুলি পরিবর্তিত হয়।
আপনি যখন একটি ফাংশনকে শিশু কম্পোনেন্টে প্রপ হিসেবে পাঠান এবং চান যে প্রপের কারণে অপ্রয়োজনীয়ভাবে শিশু কম্পোনেন্টটি পুনরায় রেন্ডার না হয়, তখন useCallback ব্যবহার করা হয়।
উদাহরণ:

useCallback ছাড়া: প্রতিবার ParentComponent রেন্ডার হলে increment ফাংশনটি নতুন করে তৈরি হবে, যার ফলে ChildComponent অপ্রয়োজনীয়ভাবে পুনরায় রেন্ডার হবে।
useCallback সহ: increment ফাংশনটি মুখস্থ থাকে এবং নির্দিষ্ট ডিপেন্ডেন্সি পরিবর্তিত না হলে পুনরায় তৈরি হয় না, ফলে ChildComponent অপ্রয়োজনীয়ভাবে পুনরায় রেন্ডার হয় না।


>>Note:In programming, memoize (or memoization) refers to an optimization technique used to speed up programs by storing the results of expensive function calls and reusing those results when the same inputs occur again. Instead of recalculating the result each time, the function retrieves the stored result, which can significantly improve performance, especially for functions that are called frequently with the same inputs.
